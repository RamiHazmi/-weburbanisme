🚗 **Ride4All**

Ride4All is a full-stack transport web application built with PHP for managing covoiturage (carpooling), parking, electronic bikes, and electric stations. The platform integrates CRUD operations, payment systems, maps, AI features, and chatbots to provide a seamless transport experience.

The project earned 2nd place in the Esprit University BAL Project 2025 (June).

🚀 **Key Features**
🏎️ **Covoiturage (Carpooling)** 

Create and manage carpool rides, including uploading pictures to the database

CRUD operations for rides (create, read, update, delete)

Find and sort rides by location, date, or availability

Chatbot for covoiturage: automatically handles user requests

SMS notifications (Twilio) for ride acceptance or refusal

🅿️ **Parking**

Book and pay via Stripe integration

Find nearby parking spots

🚲 **Electronic Bikes**

Maps showing bike stations and availability

⚡ **Electric Stations**

Payment via Stripe

Manual keyboard input with camera capture

🔐 **Authentication & Security**

Login with email and password

Password recovery workflow

Face ID authentication

ReCAPTCHA to prevent bots

📄 **Other Features**

Generate PDF reports for rides

Integrated maps and navigation for all transport modes

Project demo available on YouTube URL

🎯 **Project Goal**

Ride4All aims to provide a multi-modal transport platform, integrating carpooling, parking, bikes, and electric stations with modern features like chatbots, AI, payment systems, and maps, enhancing user experience and transport efficiency.
